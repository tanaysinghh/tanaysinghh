### [Autonomous Choke Controller](https://github.com/tanaysinghh/honeywell-choke-mpc) · Honeywell Campus Connect Hackathon
`Python` `NumPy` `Jupyter`\
Model predictive controller that adjusts the production choke of a naturally flowing oil well to hit a target flow rate while keeping wellhead, flowline, and bottomhole pressures within safe limits. Uses a plant model calibrated to Honeywell's reference data (R² ≥ 0.997) and a fallback ladder that eases off safely instead of failing when limits are tight. Zero constraint violations across 82,000+ simulated hours, and it outperforms a PI baseline. When the target rate can't be met, it reports the maximum safe rate and which pressure limit is holding it back.
